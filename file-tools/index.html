批量改名

JPG、JPEG、HEIC、HEIF 優先用 EXIF 拍攝時間。其他檔案及缺少拍攝時間的相片使用檔案修改時間。

選檔後可預覽新檔名。

原檔名新檔名時間來源

ZIP 包含改名後的副本。瀏覽器版每批上限為 250 MB。

影片轉檔及壓縮

選擇一段 DAV、MP4、MOV、MKV、AVI 或 WebM，輸出 MP4。建議在電腦使用，每段上限 128 MB。

快速模式可保留 HEVC。遇到播放相容性問題可選兼容模式。壓縮後大小視乎原片。首次使用需下載約 31 MB 的轉檔引擎。

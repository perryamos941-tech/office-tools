04 影片工具・05 命名工具：使用說明
  • 影片工具 可批量轉成 Windows 相容 MP4，並加入固定或逐秒更新的巡查日期時間。每批最多 20 段，每段上限 128 MB，每卷 ZIP 上限 256 MB。
  • 拍攝時間取自支援的影片內嵌時間或原始檔名，請與相簿核對。檔名和手動輸入按所選時區理解。選擇不顯示時區時，按香港時間處理。檔案修改時間不作推算。
  • 命名工具 優先用相片 EXIF 拍攝時間，缺少時用檔案修改時間。每批最多 3,000 個檔案、合計 250 MB。ZIP 包含改名後的副本。
  • 篩選只影響預覽。取消勾選「匯出」可排除該檔。逐檔指定時間優先於批次時間設定。
